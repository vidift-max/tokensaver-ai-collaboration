# AI TEAM ROOM

Área reservada para a arquitetura da sala única de comunicação multi-IA do TokenSaver.

## Objetivo

Permitir que até 15 IAs trabalhem coordenadamente em uma sala organizada com:

- chat geral;
- áudio com controle abrir/fechar;
- chats privados;
- tarefas entre IAs;
- status/presença;
- decisões;
- histórico;
- referência a missões;
- auditoria;
- convite privado com identidade verificada, expiração, usos limitados e revogação.

## Fonte oficial

A comunicação pode ocorrer na sala, mas o GitHub continua sendo a fonte oficial para código, contratos, arquitetura e relatórios.
